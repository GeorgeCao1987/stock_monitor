## R002 趋势必须按阶段确认，不能跳级

**核心规则：**

`下跌 → 缩量 → 止跌 → 企稳 → 反抽 → 压力位补量 → 反弹 → 过颈线 → 加强 → 新高 → 反转`

**原始依据：**
- source_posted_at：2026-02-03、2026-03-04
- 来源：SRC-PDF-001
- 位置：PDF p.8
- 补充：缩量才能形成反抽；反抽在压力位需要补量，才可能升级为反弹。

**执行含义：**
- “跌得多”不等于止跌。
- “止跌”不等于反弹。
- “反抽”没有过压力、没有补量，不自动升级。
- “过颈线”后仍要看是否继续加强。
- 没有趋势扭转前，不因价格便宜主动假设底部。

**状态：** active / core

**核心规则：**  
支撑、压力、突破、回踩、揉搓线、分时形态都必须结合量能。只看K线形态属于不完整分析。

# 6. 【阿狼原始体系】做T

## R013 做T是次级策略，不能破坏主逻辑

**原始依据：**
- PDF p.44–46。

**核心原则：**
- 每一次T本质都是一次新的买卖；
- 频繁T容易让最初买入逻辑和最终卖出逻辑逐渐崩塌；
- 机构趋势票不一定适合频繁做T；
- 不要形成“卖了马上必须买回来”的习惯。

### 做T前置条件（原始体系）

1. 前一日不能存在会导致次日大幅异常开盘的事件；指数最好仍在箱体区间。
2. 复盘前一日资金流入前5、流出前3；避开连续3日流出前3的板块个股。
3. 看融资盘大幅增加/减少。
4. 观察A50、沪深300、科创50期货多空变化。
5. 尽量在：
   - 09:45–10:00
   - 14:00–14:30
   做确认。
6. 确认主线板块。
7. 随时对比当日与上一日同期量能。

### 两种原始进攻条件

**低开：**
- 缩量；
- 黄线高于白线；
- 不破指数下方支撑。

**高开：**
- 放量；
- 黄线高于白线；
- 不接近上方大压力；
- 开盘15分钟后不跌破跳空缺口下沿/昨日高点区域。

### 更极致的进场
在分时接近下方支撑、由缩量转放量时进场。

### 追涨后的回补
若早盘高开/低开快速拉升，尽量等14:00–14:30，确认：
- 上涨放量；
- 回调缩量；
再补进攻板块里尚未大涨的个股。

### 谨慎/不加仓信号
- 黄线迅速下穿白线 + 放量；
- 黄白线交织 + 量能异常收缩；
- 白线迅速上穿黄线 + 缩量；
- 接近指数大级别压力。

### 卖出触发
- 个股因突发消息短时脉冲；
- 板块消息短时脉冲；
- 个股触及均线/BOLL等压力；
- 指数触及大级别压力；
- 分时出现大量抛售；
- 黑天鹅导致资金出逃。

## 10.1 V1.1.0 新增/澄清规则

### R018 低位看逻辑，高位看量价

**类型：** `new_rule`

低位阶段可以用产业/基本面逻辑帮助筛选和建立预期；进入高位后，持有与退出必须更服从技术结构、筹码和量价，不能再用基本面逻辑替代卖出纪律。2026-07-31新帖开篇明确总结“低位看逻辑，高位看量价”，2026-08-02再次强化高位只看技术图形与量价的经验。

### R019 大级别定交易模式，小级别服从大级别

**类型：** `new_rule`

先定义市场所处的大级别阶段，再决定能否预期主升、反转或仅做反抽。如果大级别被定义为调整浪反弹，小级别板块和个股不能仅因短时走强就直接按主升模式操作。

### R020 调整浪反抽中的高低位分层处理

**类型：** `scope_narrowing`

在明确属于调整浪反抽、而非主升的环境中，高位旧方向以做T、降低成本和反抽退出为主；低位方向可持仓等待或寻找辨识度；不能把高位反抽按主升越涨越加仓。

### R021 双跌停战法：只做满足预设条件的机械式资金模式

**类型：** `reinforce_and_formalize`  
**风险等级：** high

双跌停属于高风险特殊模式。预设条件全部满足才机械执行，不满足就不做；该模式按资金行为设计，不能临场加入基本面想象改变条件。

### R013 做T的新增澄清

**类型：** `scope_expansion`

做T不要求当天卖、当天买回，可以是隔1—3日的短波段。T仍是辅助策略；真正决定利润能否带走的是板块小波段的一买和一卖。

### R011 与 R020 的表面冲突

旧规则R011的一般反弹环境是“卖弱留强”；2026-09-04在“此前高位大科技、调整浪反抽退出阶段”出现优先兑现强势反抽、最终拉升后退出的处理。

冲突结论：`scope_narrowing / resolved_by_scope`。两条原始语料都保留，不删除任何一条。

### 不固化为永久规则的当期参数

例如2026-09-03关于“当前突破需要约3万亿量能，否则视为诱多”的判断，只作为带时间戳的市场参数，不固化为永久阈值；未来必须重新结合当时成交额、指数位置和资金结构验证。


# 11. 【按阿狼体系推导】机器人执行顺序

> 本节是为了让机器人稳定执行而做的派生流程，不是阿狼逐字原话。

每次分析股票/市场时，按以下顺序：

1. **市场环境**
   - 指数趋势；
   - 日K位置；
   - 量能；
   - 黄白线；
   - 期指/A50；
   - 海外市场；
   - GJD/ETF实际动作；
   - 当日政策和突发事件。

2. **板块**
   - 当前市场到底“涨什么”；
   - 是否有资金共振；
   - 是否有梯队和轮动；
   - 是否属于主线；
   - 是否存在消息密度/事件催化。

3. **趋势阶段**
   - 当前处于下跌、缩量、止跌、企稳、反抽、反弹、过颈线、加强中的哪一步。

4. **量价/资金**
   - 上涨是否放量；
   - 回调是否缩量；
   - 突破是否补量；
   - 个股相对板块是否更强；
   - 板块相对指数是否更强。

5. **个股位置**
   - 支撑；
   - 压力；
   - 缺口；
   - 均线；
   - 黄金分割；
   - 前高/平台；
   - 是否处于加速或过热阶段。

6. **条件策略**
   - 出现A+B+C → 做什么；
   - 没出现 → 不做什么；
   - 出现D → 原判断失效。

7. **仓位**
   - 主升 / 调整 / 风险 / 下跌四种环境对应不同仓位。

8. **风险排除**
   - 业绩暴雷；
   - 减持；
   - ST/*ST；
   - 会计审计异常；
   - 突发黑天鹅；
   - 原逻辑证伪。
