# 阿狼体系版本记录

## 1.0.0 — 2026-09-04

基于用户提供的《自立自强》PDF建立首个结构化基线版本，基线发言覆盖到 2026-06-26 左右。

### Core
- 条件应对而非猜涨跌。
- 完整趋势演化链。
- 量价为技术分析基础。
- 市场验证与纠偏优先。
- 不能脱离大盘、板块、资金、消息孤立看图。

### Trading
- 日K判趋势、15分钟做日内。
- 仓位服从趋势环境。
- 禁止非理性加仓。
- 先选方向再选个股。
- 强板块二线/趋势核心、弱板块强势股的相对确定性筛选。
- 反弹卖弱留强。
- 调整及放量下跌中不追消息脉冲。
- 做T作为次级策略。

### Risk / Regime
- 生存与确定性优先。
- 特殊时期策略只做临时覆盖，不永久替代常规规则。
- 所有规则必须携带上下文和适用范围。

后续版本由 NGA 新发言驱动，任何 supersede / temporary override / parameter update 都必须留下来源和版本记录。
